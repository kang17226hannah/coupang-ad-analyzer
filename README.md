# 쿠팡 광고 분석기

쿠팡 광고 보고서를 브라우저에서 분석하는 정적 웹앱입니다. XLSX/XLS/CSV 업로드와 RAW 붙여넣기를 지원하며 데이터는 외부 서버로 전송되지 않고 브라우저에 저장됩니다.

## 실행

```bash
npm install
npm run dev
```

## 지원 분석

- 대시보드와 광고비, 매출, 주문, ROAS, CPA, 예상 순이익, 유입 추정
- 누수/효자 키워드와 상품/지면/행별 진단
- 상품 마스터 및 수익 계산 기준 설정
- 날짜 기반 주간 데이터 누적 저장과 이번 주/지난주 및 상품ID별 비교
- VAT 포함 실제 광고비·ROAS·CPA, 상품별 필요 ROAS와 액션/퍼널 진단
- 검색·비검색·오디언스 플러스 지면 분석 및 비검색 광고비 경고
- 누수 키워드 3단계, 상품별 주간 메모와 자동 주간 요약
- 상품별 `누수 · CPC 분석` 우선순위 카드, 상태 필터와 손익분기 CPC 안내

기존 `coupang-rows`, `coupang-settings` 브라우저 저장소 키를 그대로 사용하므로
업데이트 전 데이터도 유지됩니다. 새로 업로드한 데이터는 날짜와 상품/키워드/지면을
기준으로 기존 데이터와 합쳐집니다.

GitHub Pages 배포는 `.github/workflows/deploy-pages.yml`에서 자동으로 수행합니다.
