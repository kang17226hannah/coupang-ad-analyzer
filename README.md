# 쿠팡 광고 분석기

쿠팡 광고 보고서를 브라우저에서 분석하는 정적 웹앱입니다. XLSX/XLS/CSV 업로드와 RAW 붙여넣기를 지원하며 데이터는 외부 서버로 전송되지 않고 브라우저에 저장됩니다.

## 실행

```bash
npm install
npm run dev
```

## 주간 사용 흐름

1. 최근 7일 광고보고서 또는 RAW 데이터를 업로드합니다.
2. **이번 주 데이터 저장**을 눌러 주차별 스냅샷을 보관합니다.
3. 대시보드에서 지난주 대비 KPI와 자동 요약을 확인합니다.
4. 상품별 액션, 누수, 검색/비검색 비중을 점검하고 다음 주 메모를 남깁니다.

## 지원 분석

- 광고비와 VAT 포함 실제 광고비, 매출, 주문, ROAS, 실제 ROAS, CPA, 예상 순이익, 유입 추정
- 주차별 데이터 저장, KPI·상품ID별 지난주 비교 및 규칙 기반 주간 요약
- 3단계 누수/효자 키워드와 상품 퍼널/검색·비검색/행별 진단
- 상품별 필요 ROAS, 다음 주 액션 제안과 주간 메모
- 모든 자동 판단 기준을 조정할 수 있는 설정

기존 데이터와 설정은 브라우저 `localStorage`의 기존 키를 그대로 사용하며, 주간 기록과 상품 마스터, 메모는 별도 버전 키에 저장됩니다.

GitHub Pages 배포는 `.github/workflows/deploy-pages.yml`에서 자동으로 수행합니다.
